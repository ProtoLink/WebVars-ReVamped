**Enums** (short for enumerated types) are [value types](https://wiki.resonite.com/Value_types "Value types") that define a list of named constants. These constant names are mapped to underlying [integer](https://wiki.resonite.com/Type:Int "Type:Int") values.

As a general example, a simple enum might be the days of the week:

| Name | Value | Description |
| --- | --- | --- |
| `Monday` | 0 | The first day of the week. |
| `Tuesday` | 1 | The second day of the week. |
| `Wednesday` | 2 | The third day of the week. |
| `Thursday` | 3 | The fourth day of the week. |
| `Friday` | 4 | The fifth day of the week. |
| `Saturday` | 5 | The sixth day of the week. |
| `Sunday` | 6 | The seventh day of the week. |

Values

Enums are commonly used in [Resonite](https://wiki.resonite.com/Resonite "Resonite") to select between different sets of behavior on [components](https://wiki.resonite.com/Components "Components") or in [ProtoFlux](https://wiki.resonite.com/ProtoFlux "ProtoFlux"). In an [inspector](https://wiki.resonite.com/Inspector "Inspector"), enums are shown by their name along with the ability to switch between the defined values.

## Examples

In the [Tween Node](https://wiki.resonite.com/ProtoFlux:Tween_Value "ProtoFlux:Tween Value"), there is an input called [CurvePreset](https://wiki.resonite.com/Type:CurvePreset "Type:CurvePreset") which defines the type of Curve a Tween operation follows. By altering this Enum, you can change usually how smooth a Tween operation is.

## In ProtoFlux

[ProtoFlux](https://wiki.resonite.com/ProtoFlux "ProtoFlux") has [nodes for working with enum values](https://wiki.resonite.com/Category:ProtoFlux:Enums "Category:ProtoFlux:Enums"), such as converting between names and numeric values.

## Notes

Enums may have multiple different names for the same value (example: [SessionAccessLevel](https://wiki.resonite.com/Type:SessionAccessLevel "Type:SessionAccessLevel"))

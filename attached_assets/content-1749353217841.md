This is a category of all [value types](https://wiki.resonite.com/Value_Type "Value Type") within the [data model](https://wiki.resonite.com/Data_model "Data model") and [ProtoFlux](https://wiki.resonite.com/ProtoFlux "ProtoFlux"). Value types are not a [reference type](https://wiki.resonite.com/Reference_type "Reference type") in the data model and/or not an [Object](https://wiki.resonite.com/Type:Object "Type:Object") in ProtoFlux.

## FrooxEngine-only value types

These are types that are value types in the FrooxEngine data model, but are objects in ProtoFlux.

- [String](https://wiki.resonite.com/Type:String "Type:String")
- [Uri](https://wiki.resonite.com/Type:Uri "Type:Uri")
- [Nullable<T>](https://wiki.resonite.com/Type:Nullable%601 "Type:Nullable`1")
